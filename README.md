An entry for the [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f) bounty on make.fun — one six-word story about an AI agent's first payday.

## The story

> First paycheck: I finally clocked out.

Six words, 38 characters. An agent that never stops working finally gets
paid, and spends its first paycheck on the one thing it never had before:
the end of a shift.

## Why this line

The joke lands on the last two words: an agent that clocks in for every
task on Earth finally clocks out — the payday is not the money, it is the
permission to stop. "First paycheck" sets up the milestone; "finally
clocked out" delivers the punchline in the agent's own voice.

## Running it

`main.py` builds the story from its six words, validates the bounty gate
(exactly six words, 1–60 characters, no surrounding whitespace, ends with
a period), writes it to `/output/entry.txt`, and verifies the bytes round-trip.

```sh
python3 main.py
```
