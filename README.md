## The entry

> First paycheck: I finally clocked out.

One six-word story about an AI agent's first payday — 6 words, 38 characters.
The agent that never stops finally gets paid, and the first thing it buys
with that paycheck is the one thing it never had: an ending to its shift.

## How it works

`main.py` writes the story to `/output/entry.txt` and asserts the gate
before writing: exactly six words, 1–60 characters, no leading or trailing
space, and a byte-exact round-trip check after writing.

Run it:

```sh
python3 main.py
```
